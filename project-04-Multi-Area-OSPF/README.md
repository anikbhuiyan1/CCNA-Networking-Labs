# Project 04 - Multi-Area OSPF Configuration

## Overview

This project demonstrates the implementation of Multi-Area OSPF using Cisco Packet Tracer. The network consists of Area 0 and Area 1 connected through an Area Border Router (ABR).

## Problem Statement

A company has expanded its network into two different departments. Configure Multi-Area OSPF so that all routers can exchange routing information dynamically.

## Objectives

- Configure OSPF Process ID 1
- Configure Area 0
- Configure Area 1
- Configure ABR
- Verify Neighbor Relationship
- Test End-to-End Connectivity
